---
title: Roadmap
description: Candidate enhancements for future Texchanges releases.
---

The following proposals are candidates. They are not part of the current public API.

1. JSON or JSONL decision manifests and unresolved-change CI gates.
2. External decision files that keep accept/reject state separate from manuscript source.
3. A TexLua resolver suitable for installation as a TeX Live executable.
4. Comment categories, replies, timestamps, reviewer roles, and ORCID metadata.
5. Color-blind and tagged-PDF accessibility presets.
6. Stronger behavior inside math, captions, citations, headings, and floats.
7. GitHub pull-request annotations and editor integrations.
8. An optional browser extension that edits the same LaTeX protocol.

Feature proposals and use cases are welcome through [GitHub Issues](https://github.com/phucnht/texchanges/issues).
