Texchanges supports two complementary workflows. Use explicit review markup when decisions belong in the LaTeX source, or use automatic `latexdiff` to compare two complete revisions.

## Explicit review

The [explicit review example](https://github.com/phucnht/texchanges/tree/main/examples/explicit-review/) keeps additions, removals, replacements, and decisions in one LaTeX source file. Change `\texchangesexamplemode` to compile the same source for review, final, or original reading.

Source: [`texchanges-explicit-review.tex`](https://github.com/phucnht/texchanges/blob/main/examples/explicit-review/texchanges-explicit-review.tex) · [Overleaf instructions](https://github.com/phucnht/texchanges/blob/main/examples/explicit-review/README.md)

## Automatic `latexdiff`

The [automatic diff example](https://github.com/phucnht/texchanges/tree/main/examples/automatic-diff/) compares two complete revisions. Select `texchanges-review.tex` as the Overleaf Main document, then `latexmkrc` runs word-level `latexdiff` before pdfLaTeX compiles the generated review document. The example covers a removed word, phrase replacement, insertion, formatted text, and a revised list.

Sources: [`texchanges-original.tex`](https://github.com/phucnht/texchanges/blob/main/examples/automatic-diff/texchanges-original.tex), [`texchanges-revised.tex`](https://github.com/phucnht/texchanges/blob/main/examples/automatic-diff/texchanges-revised.tex), [`latexmkrc`](https://github.com/phucnht/texchanges/blob/main/examples/automatic-diff/latexmkrc) · [Overleaf instructions](https://github.com/phucnht/texchanges/blob/main/examples/automatic-diff/README.md)
